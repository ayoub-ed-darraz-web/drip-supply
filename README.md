# 💧 Drip Supply

A modern streetwear e-commerce web application designed for browsing and shopping urban fashion, apparel, and accessories.

## ✨ Features
- Clean, responsive streetwear storefront UI
- Product catalog with categories and filtering
- Product detail pages (sizes, pricing, and descriptions)
- Interactive shopping cart (add, remove, and update quantities)

## 🛠️ Built With
- **HTML5** – Structure
- **CSS3** – Styling and responsive layout
- **JavaScript** – Interactivity and cart logic
